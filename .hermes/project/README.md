# Calculator Application Documentation

The target product is a small Python command-line calculator. The documentation focuses on its user-facing behavior, product scope, and technical design:

- [Product Requirements](PRD.md): users, functionality, constraints, and product boundaries.
- [Architecture](ARCHITECTURE.md): runtime components, responsibilities, and data flow.
- [Technical Specification](TECHNICAL_SPEC.md): exact arithmetic API and command-line behavior.

The product requirements define what the calculator must do. The architecture defines its component boundaries. The technical specification resolves the observable interface details needed to implement those requirements consistently.
